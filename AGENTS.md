# Personal Blog Instructions

Read PROJECT.md and README.md for build and publishing entry points. Edit site settings in `shirones/config/`. Place theme overrides under `src/`; version theme upgrades through `package.json` and `pnpm-lock.yaml`.

The Obsidian vault contains the authors' originals. Publishing to `shirones/content/posts/`, `shirones/content/moments/`, and `public/blog-media/` is handled by Enveloppe. The local moments page shares the Obsidian Markdown processor with articles. Run `pnpm build` after changing site, publishing, or theme code.
